## 📦 Overview

**OrbatGen** helps you automate the generation of operational order slides in PowerPoint format based on a structured representation of units, their hierarchy, and their equipment.

---

## 🚀 Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run the main script
python main.py
```

---

## 🧱 Project Structure

- `main.py` — Entry point to launch the generation.
- `orbat_gen/` — Core logic for units, equipment, and PowerPoint rendering.
- `data/` — CSV files containing your structured unit info.
- `img/` — Visual symbols used in PowerPoint generation.
- `tests/` — Testing directory
